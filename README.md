# Business Analysis Internship Project
## Customer Churn Analysis | Saiket Systems

### Project Overview
This project analyzes a telecommunications customer dataset containing 7,043 records to identify customer churn patterns and generate meaningful business insights.

### Objectives
- Explore and understand customer data.
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Segment customers based on tenure.
- Analyze customer churn patterns.
- Develop data-driven recommendations.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Visual Studio Code

### Key Findings
- Overall customer churn rate: 26.54%.
- Month-to-month contract churn rate: 42.71%.
- Churn rate among customers with 0–12 months of tenure: 47.44%.
- Electronic check users' churn rate: 45.29%.

### Project Structure
- `Business_Analysis.ipynb` – Main analysis notebook.
- `data/` – Dataset directory.
